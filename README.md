# anonchat

Anonchat is a test project for vibe coding. I wanted to create a useful application completely generated by AI. For this particular purpose I chose a field that I myself am not skilled in so that I can't be tempted to add any code to the project myself. So this is a kind of a proof-of-concept project.

In PROMPTS.md there's a collection of the prompts, used to generate the application.
